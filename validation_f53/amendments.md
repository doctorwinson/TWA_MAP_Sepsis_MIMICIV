# Audit-driven amendments

These changes address implementation and source-data findings. No thresholds or subgroup definitions were chosen to improve statistical significance.

1. Source-cache mismatch: the available minimal cache retained the older m=5 first imputation. Reconstruct all 40 imputations using the preserved pre-imputation observations and source function. The rebuilt F52 estimate and exact threshold rounding match the submitted manuscript.
2. Sepsis timing: 764 of 7,770 pre-imputation patients have recorded Sepsis-3 onset after the landmark. Retain the original cohort for reproduction and explicitly add restriction to established sepsis by 24 h. Future main-manuscript revision must address this eligibility issue.
3. Missing SOFA components: the source SQL retains NULL components and sums them with COALESCE(component,0). Verify that scoring missing components as zero exactly reproduces every source total, preserve component missingness, and report both conventional scored-zero full-cohort analyses and complete-domain cases. Source: https://raw.githubusercontent.com/MIT-LCP/mimic-code/main/mimic-iv/concepts/firstday/first_day_sofa.sql . This convention is not proof that unmeasured organ function was normal.
4. Enriched imputation: add phenotype variables, SOFA domains and sepsis-by-landmark status as MAP predictors. Exclude total SOFA from the predictor matrix when all six components enter, then rejoin the original total for the outcome model. Use complete-domain and full-cohort scored-domain sensitivity analyses. The latter includes component-missingness indicators. Factor gender explicitly; the legacy reproduction logged character gender as an excluded constant predictor.
5. Sparse interactions: omit factor levels with <50 patients or <10 events only from the corresponding interaction test, report the denominator and suppression, and use D1 MI pooling. Treat all six interaction tests, including temporal interaction, as one exploratory BH-adjusted family. Period interaction uses the observed-hour cohort and a likelihood-ratio test.
6. PH diagnostics: report Schoenfeld tests as diagnostics on imputation 1, not pooled p-values. A global model violation is not equivalent to a MAP-specific violation. Add prespecified-at-QC early/late follow-up contrasts (ICU days 1-7 and 7-30); these are additional post hoc sensitivity results.
7. eICU: use in-hospital death and a shared covariate set; apply hospital/patient multiway-clustered uncertainty with hospital-count degrees of freedom. Existing local infection-proxy timing is a sensitivity flag, not independently verified Sepsis-3 construction. Do not call the analysis definitive external validation.
